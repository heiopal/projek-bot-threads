# Kebijakan Privasi — RexMand (Threads Bot)

**Terakhir diperbarui:** 23 September 2026

Aplikasi ini ("RexMand") adalah proyek pribadi untuk keperluan belajar otomatisasi Threads API, dikembangkan dan dioperasikan oleh individu (bukan perusahaan/organisasi). Aplikasi ini hanya digunakan untuk mengelola satu akun Threads milik pengembang sendiri.

## Data yang Diakses

Melalui izin (permission) yang diberikan lewat Threads API, aplikasi ini dapat mengakses:
- Profil dasar akun Threads (username, ID akun)
- Postingan yang dibuat lewat akun tersebut
- Balasan (reply) yang masuk ke postingan akun tersebut

## Bagaimana Data Digunakan

Data di atas digunakan semata-mata untuk:
- Membuat postingan baru secara otomatis ke akun Threads milik pengembang
- Membaca dan membalas komentar/reply yang masuk ke postingan milik akun tersebut

Aplikasi ini **tidak** mengakses, mengumpulkan, atau memproses data dari akun Threads milik pengguna lain, kecuali teks komentar publik yang memang ditujukan sebagai balasan ke postingan milik akun yang dikelola.

## Penyimpanan Data

Sebagian kecil data (ID reply yang sudah diproses) disimpan secara lokal di perangkat/server milik pengembang sendiri, hanya untuk mencegah balasan ganda. Data ini tidak dibagikan ke pihak mana pun.

## Berbagi Data ke Pihak Ketiga

Aplikasi ini **tidak** menjual, menyewakan, atau membagikan data apa pun ke pihak ketiga. Teks konten dikirim ke Google Gemini API semata-mata untuk menghasilkan draf teks balasan/postingan, sesuai kebijakan privasi Google.
