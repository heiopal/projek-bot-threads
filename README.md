# StudyP4L Meta Threads Bot

Autonomous AI assistant for Meta Threads (@studyp4l) driven via Telegram.

## Features
- **Brainstorming & Angle Selection**: Proposes 3 distinct angles (Relatable, Pro-Tip, Hot Take) before drafting.
- **Content Engine & Brand Voice**: Platform-native copy tailored for Indonesian tech students / developers.
- **Pre-Publish Verification**: Enforces <500 character limit and explicit confirmation.
- **Direct Graph API Publishing**: Posts directly to Meta Threads.
- **GitHub Persistent Storage**: Syncs post history to `content_history.json` permanently.
- **Keep-Alive Server**: Web status dashboard on port 7860 for 24/7 uptime monitoring.
